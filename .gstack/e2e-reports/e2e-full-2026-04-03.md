## Bugs Found

### BUG-001: Paper Exchange Accepts Any Symbol (E-001 FAIL)

**Severity:** MEDIUM
**File:** `src/services/exchange/paper-trading.ts`
**Issue:** `PaperExchange` has no symbol validation. Any string (e.g., "FAKECOIN/USDT") is accepted and assigned a simulated price of $50,000. The `InvalidSymbolError` in `ccxt-client.ts` only fires for real exchange connections.
**Impact:** Users can accidentally trade non-existent symbols in paper mode with no warning.
**Fix:** Add a symbol allowlist check in `PaperExchange.placeOrder()` against the `POPULAR_PAIRS` list or a configurable symbol registry.

### FINDING-001: Debate Never Fires When Gate Fails First (G-003 PARTIAL)

**Severity:** LOW (by design)
**File:** `src/services/trading/guardian-observer.ts`
**Issue:** When PreTradeGate returns FAIL, the order is blocked before `shouldTriggerDebate()` is evaluated. This means the adversarial debate feature only fires for orders that pass the gate — which may be the intended behavior (why debate an order that's already blocked?).
**Impact:** Users never see the debate format for obviously bad trades. The gate provides sufficient protection, but the debate feature is underexercised.
