# Vibe Sensei — Guardian Sprite Prompts

每个角色需要生成 **6 个状态** 的 sprite sheet：
1. **idle** — 默认待机（坐着/站着，轻微呼吸动画）
2. **active** — 认真分析中（看图表/翻书/计算）
3. **happy** — 交易盈利/止盈成功（微笑/鼓掌/点头）
4. **worried** — 交易亏损/风险升高（皱眉/摇头/叹气）
5. **alert** — 触发警告/大额下单（拍桌/举手/警告手势）
6. **celebrate** — 大赚/里程碑（欢呼/跳跃/庆祝）

## 全局风格指令

```
Style: pixel art sprite, 120x120px, transparent background, chibi/cute proportions (大头小身), 
clean outlines, limited 32-color palette, suitable for dark UI background (#0B0E14).
Each character should be instantly recognizable by their iconic visual traits.
Do NOT include any text or labels in the sprite.
```

## 生成注意事项

1. **统一尺寸**: 所有 sprite 120×120px，透明背景 PNG
2. **6 个状态**: idle / active / happy / worried / alert / celebrate
3. **命名规则**: `{master_id}-{state}.png`，例如 `jesse_livermore-idle.png`
4. **Ghost 前缀**: ghost sprite 用 `ghost-{id}-{state}.png`
5. **调色板**: 适配深色 UI 背景 `#0B0E14`，角色本身要明亮够辨识
6. **一致性**: 同一角色 6 个状态之间要保持面部/服装一致，只改表情和姿势
